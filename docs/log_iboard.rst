LogiBoard Integration
=====================

The ``LogiBoard`` in the ``fastapi_logging_kit`` package provides an interface for uploading, extracting, and exploring log files that have been zipped and shared via email. This allows for easier log management.

.. note::

   **Restricted Access**: access is controlled by a replaceable permission predicate. The default implementation denies anonymous requests and requires ``is_superuser`` on ``scope["user"]``. The application must install authentication middleware that populates ``scope["user"]`` (for example, Starlette's ``AuthenticationMiddleware``); without an authenticated user, access is denied with ``403``.

Setup Instructions
------------------

1. **Enable LogiBoard**:
   Set ``INCLUDE_LOG_iBOARD`` to ``True`` in your configuration:

   .. code-block:: python

      setup_logging(app, {"INCLUDE_LOG_iBOARD": True})

   That registers the page at ``/log-iboard/`` and mounts its assets at ``/fastapi-logging-kit/static``. There is no separate static-file collection step — the packaged assets are served by the application itself.

2. **Restrict access**:
   FastAPI has no built-in permission framework, so access is controlled by a predicate you can replace. The default reads ``is_superuser`` from ``scope["user"]`` and **denies anonymous requests**. Install authentication middleware to populate that scope value.

   Prefer an application-scoped predicate when configuring a specific app. This prevents policies from leaking between multiple FastAPI applications in the same process:

   .. code-block:: python

      from fastapi import FastAPI
      from fastapi_logging_kit.routers import set_permission_check


      app = FastAPI()


      def only_admins(request) -> bool:
          user = request.scope.get("user")
          return bool(user and user.role == "admin")


      set_permission_check(only_admins, app=app)

   Calling ``set_permission_check(check)`` without ``app`` remains available as a process-wide default for compatibility. Permission callbacks must be synchronous and return a real ``bool``; asynchronous callbacks and non-boolean results are rejected rather than treated as truthy.

Using LogiBoard
---------------

LogiBoard is designed to help administrators easily review log files that have been zipped and sent via email (generated by the ``fastapi-logging-kit send-logs`` command). This is particularly useful for remotely retrieving log files from production systems or shared environments.

- **Access LogiBoard**: Go to the link ``/log-iboard/`` in your project to open the LogiBoard interface.
- **Upload ZIP Files**: Click the upload icon or drag and drop ZIP files into the upload area. Only ZIP files are supported for upload.
- **Explore Log Files**: After uploading, LogiBoard automatically extracts the log files and displays their structure. You can browse through directories and preview log files in supported formats, such as ``JSON``, ``XML`` and ``txt``.
- **Upload New Files**: Once you're done reviewing, click the "Send Another" button to upload and explore more logs.

LogiBoard makes it simple to manage and review logs, ensuring you can quickly access and analyze critical log data.
